Every minute, every room, straight off the sensor.

Thermal Survey is a small Go web app that pulls per-minute temperature and humidity history out of three Govee H5179 thermometers over Bluetooth, stores it in MySQL and draws it as charts. It runs on a laptop, needs no cloud and recorded the day the heat pump died.

Sheet 1

System schematic

Readings take three routes into one MySQL cache. The main one is Bluetooth: every three hours the laptop connects to each sensor and downloads every minute it hasn't seen yet. The Govee cloud fills in a rough "right now" between syncs, and CSV exports from the Govee app back-fill anything older than the sensors' 20-day memory.

Sheet 2

Why not just use the Govee API?

The first version polled Govee's official cloud API every two minutes. Then the data said otherwise: for 62 minutes the API returned the same 70.55 °F while the sensor itself logged the room moving through seven different temperatures. The cloud copy goes stale. The sensor's own log doesn't.

  • Sensor's own minute log (Bluetooth / export)
  • Govee cloud API, polled every 2 min

Downstairs, Nov 20, 4:10–5:30 PM Pacific. Both series are real readings.

Cloud value unchanged for 62min

Meanwhile the sensor saw 7 distinct temperatures and 15 humidity values. The cloud value finally moved one minute after someone synced the sensor in the Govee phone app.

What the sensor keeps 28,800readings

That's 20 days at one per minute. Any device that can speak its Bluetooth protocol can download all of it, so the laptop only needs to be home once every 20 days to miss nothing.

        The last heating cycle ran at 7:37 PM the night before. No room got its morning warm-up; the Master Bedroom sank to 66.4 °F by 10 AM. Heat came back at 3:57 PM. It's the one day in the record with no morning warm-up anywhere in the house.

        Downstairs humidity leapt about 12 points at exactly 4:00 AM most nights, and the bedrooms followed an hour later as the warm-up began. It never happened before Nov 4 and stopped the day the heat pump failed.

        Under the hood

        LanguageGo 1.27, standard library

        net/http routing, html/template pages, embedded templates and static files. One binary.

        ChartsHand-built SVG

        No chart library. Nice-number axes, calendar-aligned ticks, gap detection and collision-free end labels, all in chart.go.

        StorageMySQL 8.4

        One row per sensor per minute; time-bucketed averages in SQL keep every chart near 400 points.

        Radiotinygo.org/x/bluetooth

        CoreBluetooth on macOS. Remembers each sensor's address so later syncs skip the scan.

        CryptoAES-128-ECB + RC4

        Per-connection session key from the handshake. Unit tests decrypt packets captured off the real sensor.

        Uptimelaunchd login agent

        Starts at login, restarts on exit, waits for MySQL. An embedded Info.plist earns macOS Bluetooth permission.

        // decodeReading unpacks Govee's 3-byte reading.
func decodeReading(b0, b1, b2 byte) (tempC, hum float64) {
	n := int(b0)<<16 | int(b1)<<8 | int(b2)
	neg := n&0x800000 != 0
	n &= 0x7FFFF
	tempC = float64(n/1000) / 10
	if neg {
		tempC = -tempC
	}
	return tempC, float64(n%1000) / 10
}
