Import sensor history

The Govee cloud API only reports a sensor's current reading, so this terminal builds its history by polling. To back-fill older data, export it from the Govee Home app and upload it here:

  1. In the Govee Home app, open the thermometer, tap the settings gear, then Data export (or the export icon on the history chart).
  2. Choose the date range. Govee emails you a CSV.
  3. Upload that CSV below and pick the zone it belongs to. Readings already on file are skipped.

Times in the file are read as local time. °C exports are converted to °F.
